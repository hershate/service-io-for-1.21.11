# 3.0.0 —— Service-IO-1.21.11-3.0.0

> 发布件：`plugin/build/libs/Service-IO-1.21.11-3.0.0.jar`　|　目标：Minecraft 1.21.11 / JDK 21　|　字节码：Java 21（major 65）

本版本在 1.21.11 / JDK 21 fork 基础上完成**性能优化**并**确立新的发布件命名规则**，去掉 `-pre` 视作首个稳定发布版。

## 命名规则

- **新规则**：`Service-IO-<MC版本>-<版本号>.jar`
- 本版本：`Service-IO-1.21.11-3.0.0.jar`（原 `service-io-3.0.0-pre11-all.jar`）
- 落地：`gradle.properties` 的 `version=3.0.0`；`plugin/build.gradle.kts` 的 `shadowJar` 设 `archiveBaseName="Service-IO-1.21.11"`、`archiveClassifier=""`

## 性能优化（详见 [report/perf/2026-07-30-perf-optimization.md](../report/perf/2026-07-30-perf-optimization.md)）

| 项 | 改动 | 实测 |
|---|---|---|
| 占位符派发（`PlaceholderStore`） | 字面量 O(1) hash 查表 + pattern 按首段前缀分桶（前缀长度降序、桶内特异性排序）+ 字面锚点预过滤 | 派发加速 **3-16x**；消除旧实现 85-1253ns 延迟尖刺，新实现稳定 21-114ns |
| `EntityType` 查表（`CharacterController` / `EntityHologramLine`） | 启动期一次性建静态映射/过滤列表，替代每次 `values()` 分配+流式过滤 | 精确查找加速 **~60-78x**、可赋值查找 **~1.35x** |

附带修复：`PlaceholderStore` 旧 `HashMap` 迭代序不确定，致多段重叠占位符（如 `balance_%s` vs `balance_currency_%s` 对 `balance_currency_USD`）命中结果随机；现按特异性确定性解析为最具体者。

正确性门禁：benchmark 注册真实 `UnlockedEconomyPlaceholderStore` 全部 18 个 resolver（含每个重叠 pattern），断言全部文档化输入命中预期 resolver，**18/18 通过**。

经测量后**未采用**：同步经济桥 `resolve()` 加 `isDone()` 快速路径——实测 JDK 21 上 `get(5,SU)` 对已完成 future 已短路（~2-3ns），额外 `isDone()` 反而 2→3ns 略慢，非优化，已撤销。

## benchmark 模块

新增 `benchmark/` 子模块（离线、零额外依赖）：Proxy stub 替代 Mockito、手写计时替代 JMH，"前"实现为现有代码逐字拷贝。运行：

```bash
JAVA_HOME=/d/Java/21 <gradle>/bin/gradle :benchmark:run --console=plain
```
